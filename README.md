# AS — Locadora de Veículos

Projeto de Programação Orientada a Objetos (Java 21).
Sistema simples para consultar preço, alugar e devolver carros e motos.

## Conceitos aplicados
- Herança: `Carro` e `Moto` herdam de `Veiculo`
- Encapsulamento: atributos privados e só getters
- Polimorfismo: `calcularValor` executa a fórmula de cada tipo
- Classe abstrata: `Veiculo`
- Interface: `Tarifavel`

## Como executar
Abra a pasta no VS Code e execute a classe `Main`.
